Это не билет с фиксированными вопросами: на отл(10) нужно подготовить отдельный, более глубокий рассказ по теме на выбор (согласовать с лектором). Сюда стоит выбрать что-то одно и разобрать по-настоящему подробно (с примерами, кодом, нюансами) — а не пытаться покрыть все варианты сразу.

  \item Краткий доклад про инструменты для работы с многопоточным кодом в C++ (\texttt{std::thread}, \texttt{std::mutex}, \texttt{std::atomic}, гонки данных, основные паттерны синхронизации).
  \item Обзор рефлексии в C++26 (что это, зачем, как менялось обсуждение в комитете, простые примеры использования).
\end{itemize}
